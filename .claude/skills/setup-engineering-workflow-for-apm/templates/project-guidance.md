# Engineering workflow

Use `docs/agents/issue-tracker.md` for repository-specific issue operations.
Default triage roles are `needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, and `wontfix`; follow an existing repository mapping when one
is documented.

Before changing a domain area, read the relevant `CONTEXT.md`,
`CONTEXT-MAP.md`, and ADRs under `docs/adr/` when they exist. Missing domain
documents do not block work.
